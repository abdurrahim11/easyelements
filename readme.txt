## Description

**[Easy Elements](https://easyelementspro.com/)** is an all-in-one addon for Elementor Page Builder, providing everything you need to enhance your Elementor capabilities. Our plugin offers an intuitive drag-and-drop interface, making it easy to use even for beginners. Key features include:

- **Header-Footer Builder**: Create custom headers and footers with ease.
- **Mega Menu**: Design intricate and feature-rich mega menus.
- **Widgets**: Choose from a variety of pre-built widgets to enhance your site functionality.

Explore the [**Easy Elements demo**](https://easyelementspro.com/) for more insights and possibilities.

## Installation

1. Upload the plugin files to the `/wp-content/plugins/easy-elements` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. All Settings will be found in the Admin sidebar -> Easy Elements menu.

## Frequently Asked Questions

### How do the Easy Elements addons reduce the extra loading time of your WordPress website?
This well-coded addon caches API-related widget data to avoid calling directly to the API each time. Also, there is an option to deactivate unused widgets and modules.

### Does Easy Elements cause conflicts with other plugins or themes?
No, you can work seamlessly with this Elementor addon.

### Elementor editor fails to load or not working?
It's due to your servers' PHP settings. Increase your server PHP memory limit from the wp-config.php file or php.ini file. For help, please contact your hosting provider and ask to increase:
- PHP memory_limit = 512M
- max_execution_time = 300

### How can I report security bugs?
You can report security bugs by going to this [support page](https://easyelementspro.com/get-support/).
